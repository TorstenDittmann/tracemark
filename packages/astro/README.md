# @tracemark/astro

Astro integration for [tracemark](https://github.com/TorstenDittmann/tracemark): browser analytics on every page and optional server middleware.

```sh
npm install @tracemark/astro @tracemark/browser
```

Add the integration to your Astro config. For server-side feature flags and error tracking, also install `@tracemark/node` and use `@tracemark/astro/middleware`.

Requires a running tracemark instance and its project key.

[Setup and examples](https://github.com/TorstenDittmann/tracemark/blob/main/docs/frameworks.md#astro-tracemarkastro)
