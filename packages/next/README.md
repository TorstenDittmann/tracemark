# @tracemark/next

Next.js App Router helpers for [tracemark](https://github.com/TorstenDittmann/tracemark): a browser provider, server flag bootstrap and error capture.

```sh
npm install @tracemark/next @tracemark/react @tracemark/browser @tracemark/node
```

Use `TracemarkNextProvider` in your layout and server helpers from `@tracemark/next/server`. Feature flag hooks from `@tracemark/react` work inside the provider.

Requires React 18 or 19, a running tracemark instance and its project key.

[Setup and examples](https://github.com/TorstenDittmann/tracemark/blob/main/docs/frameworks.md#nextjs-app-router-tracemarknext)
